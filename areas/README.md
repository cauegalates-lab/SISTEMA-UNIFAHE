# Áreas separadas do sistema UNIFAHE

O `index.html` ficou como base principal do sistema e agora aponta para os arquivos desta pasta.

Arquivos principais:

- `home.js`: área inicial.
- `vendas.js`: área de Vendas.
- `times.js`: estrutura da área de Times comerciais.
- `times-render.js`: renderização dos cards de Times comerciais, incluindo a barra de progresso da meta.
- `treinamentos-campanhas.js`: área de Treinamentos e Campanhas.
- `comissoes.js`: área de Comissões.
- `dashboard.js`: dashboard geral.
- `dashboard-individual.js`: dashboard individual.
- `painel-indicadores.js`: ponto de conexão do Painel de Indicadores.
- `modais-globais.js`: modais usados pelo sistema.

A base, permissões, login, menu, cálculos, banco de dados e regras gerais continuam no `index.html`.
