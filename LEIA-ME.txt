1) CONFIGURAR O APPS SCRIPT
- Substitua o Code.gs pelo arquivo desta pasta.
- Abra Apps Script > Configurações do projeto > Propriedades do script.
- Crie a propriedade: META_API_TOKEN
- Gere um token forte (ideal: 32+ caracteres aleatórios) e salve como valor.
- Vá em Implantar > Gerenciar implantações > Editar > Nova versão > Implantar.
- Mantenha o Web App acessível para a Vercel (normalmente "Qualquer pessoa").

IMPORTANTE: não escreva META_API_TOKEN dentro do Code.gs. Ele deve ficar nas Propriedades do script.

2) CONFIGURAR A VERCEL
Em Project > Settings > Environment Variables, crie:

META_APPS_SCRIPT_URL
- Valor: URL /exec da implantação do Apps Script.

META_APPS_SCRIPT_TOKEN
- Valor: exatamente o mesmo valor de META_API_TOKEN do Apps Script.

DASHBOARD_LOGIN_USER
- Valor: usuário que será usado na tela de login.

DASHBOARD_LOGIN_PASSWORD
- Valor: senha do painel. Use uma senha forte.

DASHBOARD_SESSION_SECRET
- Valor: outro segredo aleatório forte, diferente da senha e do token do Apps Script.

Depois de adicionar/alterar variáveis, faça um novo deploy na Vercel.

3) GITHUB
- Não faça upload de .env nem .env.local.
- O .gitignore já bloqueia esses arquivos.
- .env.example contém somente exemplos e pode permanecer no repositório.

ARQUITETURA
Navegador -> login -> cookie de sessão -> /api/meta -> Apps Script (token secreto) -> planilha

O navegador NÃO recebe:
- URL do Apps Script
- token do Apps Script
- senha configurada na Vercel
- segredo de sessão
- ID/fórmula da planilha retornados pelo Apps Script

OBSERVAÇÃO
O estado salvo no localStorage continua existindo para carregar os últimos números rapidamente após o login. A API permanece protegida mesmo que alguém tente chamá-la diretamente.
